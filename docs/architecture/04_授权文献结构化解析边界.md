# 授权文献结构化解析边界

本模块是 CosMatter 的“文献定向仪”入口：它只把已经通过
`is_content_accessible` 门禁的候选文献，送入用户明确给出的 MinerU 远程
HTTPS 来源。它不是全文缓存、网页代理或自动证据生成器。

## 已实现的受控路径

```text
approved candidate (is_content_accessible=true)
  -> user supplies one public-looking HTTPS source URL
  -> MinerU v4 asynchronous task
  -> source_parse_tasks.json (task state + URL SHA-256 only)
  -> reviewer-selected bounded source-map -> later evidence-draft workflow
```

`mineru-submit-url` 与 `mineru-poll` 不下载解析结果，不保存 Markdown、
JSON、CDN 结果链接或源 URL。浏览器 UI 也不读取该任务账本。这样，文献
结构化能力仍在后端的授权范围内，不能绕过现有的短引文、定位信息和人工
审核门禁。

## 命令

以下命令仅在上级 `.env` 已由使用者配置 `MINERU_API_TOKEN` 时才会实际
访问 MinerU；实现和测试不会读取或展示密钥。

```powershell
./.venv/Scripts/python.exe -m cosmatter mineru-submit-url `
  --run-id bfo_live_001 --document-id sciverse_document_id `
  --source-url "https://publisher.example/authorized-paper.pdf"

./.venv/Scripts/python.exe -m cosmatter mineru-poll `
  --run-id bfo_live_001 --document-id sciverse_document_id

# 只提交人工审阅后选出的 1–12 个短片段；不会读取 MinerU 原始输出
./.venv/Scripts/python.exe -m cosmatter record-source-map `
  --run-id bfo_live_001 --document-id sciverse_document_id `
  --input ./reviewed_source_selection.json
```

`reviewed_source_selection.json` 必须仅包含同一 `document_id` 与最多 12 个
`segment_id + locator + kind + quote` 片段；每段 quote 上限 500 字符。系统仅在
对应 MinerU 任务状态为 `done` 时写入 `source_map.json`，并把 task ID 以哈希
形式关联。片段本身留在本地运行目录，绝不进入 UI JSON 或审计日志。

允许条件：候选文献属于同一运行、其 `is_content_accessible` 为真、来源为
无凭据的 HTTPS URL；客户端拒绝 `http`、localhost、`.local` 与显式私有
IP。DNS 重定向/服务端请求伪造防护仍应由文献来源与 MinerU 服务端承担，
因此不应提交内网或临时凭据 URL。

## 采用的官方契约

- 云端 v4：`POST /api/v4/extract/task` 提交 URL 和 `model_version`，随后
  `GET /api/v4/extract/task/{task_id}` 轮询。
- 后续若使用本地部署，可适配官方 `mineru-api` 的 `POST /tasks`、
  `GET /tasks/{task_id}` 与 `GET /tasks/{task_id}/result`；本项目当前没有
  启动本地服务，也不拉取结果。

该阶段完成的是“授权解析任务溯源”与“人工复核的 source-map”，但二者都不是已验证的科学证据。下一阶段才可由人工基于 source-map 生成现有 `ingest-evidence` 所需的窄证据草稿。
