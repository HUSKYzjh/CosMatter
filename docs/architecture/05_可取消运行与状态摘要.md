# 可取消运行与状态摘要

Frontier Lens 的进度交互在 CosMatter 中采用“协作式取消”实现。当前第三方
请求均为同步调用，不能安全地声称可以终止已在网络中的请求；取消只保证阻止
该运行之后的 DeepSeek、Sciverse 与 MinerU 外部提交。

## 控制工件与命令

```powershell
./.venv/Scripts/python.exe -m cosmatter cancel-mission --run-id bfo_live_001
./.venv/Scripts/python.exe -m cosmatter run-status --run-id bfo_live_001
```

`cancel-mission` 写入 Git 忽略的 `runs/<run_id>/run_control.json`，其中仅有
schema、任务 ID、取消状态与时间；不保存原因、查询、密钥、请求 ID 或错误原文。
该命令可重复执行。`run-status` 只返回 `run_id`、`mission_id`、状态、终态布尔
值与取消可用性，供后续仅监听 `127.0.0.1` 的只读服务或 UI 轮询使用。

取消后，下列会发起外部调用的命令在出网前被拒绝：`draft-plan`、
`execute-plan-query`、`mineru-submit-url` 与 `mineru-poll`。本地审核、导出及
历史阅读仍可进行。UI 导出的时间线只呈现“已取消；未启动后续外部请求”，不
泄露控制工件或审计 payload。
