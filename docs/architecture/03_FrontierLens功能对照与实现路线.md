# FrontierLens 功能对照与 CosMatter 实施状态

本文件以本地参考副本 `02_Reference/11_sciverse_frontier_lens` 的 README、用户指南和架构决策为准，并以 CosMatter 当前源码、CLI 工件和测试为准。目标是迁移其“有界、可回溯、渐进披露”的科研阅读方法，而不是复制其 AI 会议语料、前端配置方式或任何内部数据实现。

## 已对齐的能力

| FrontierLens 能力 | CosMatter 当前实现 | 证据与边界 |
| --- | --- | --- |
| 有界任务/主题图 | `MissionBrief`、已批准 `FlightPlan`、候选工件和 `network.html` | 图只来自当前运行白名单工件，不是全局文献图。 |
| Research Guide / Roadmap | `build-reading-guide`、`workflow.html`、`extensions.html` | 主检索、反例检索和已核验证据分轨；拓展草案只使用脱敏运行上下文。 |
| 论文导读 | `paper.html` 的导读与证据视图 | 显示候选元数据、已批准短摘录及授权解析后的人工复核片段；不加载全文。 |
| 论文内实体与关系 | `paper_structure.py`、`record-paper-structure`、论文结构视图 | 实体身份为 `entity:{document_id}:{entity_id}`；关系需绑定同篇文献的复核片段，使用有限的非因果语义。 |
| 实体回溯来源 | 论文结构实体可回跳并高亮 `source_map` 片段 | 仅回溯人工复核、有限长度的授权解析片段；没有片段时不伪造跳转。 |
| 区分关系语义 | 星图区分出处、支持、反驳、待核查、报告条件、OpenAlex 引用/相关和 Crossref 参考 | 所有外部书目关系都标注为非科学证据；报告条件也明确非因果。 |
| 两个公开书目来源 | `openalex.py`、`crossref.py` 及各自关系工件 | 仅接受已批准且带 DOI 的证据卡触发；关系数量受限，审计日志不写目标标识。 |
| 可取消任务与进度摘要 | `run_control.py`、`cancel-mission`、`run-status`、时间线投影 | 取消为协作式；不能中断已在途的同步 HTTP 请求。 |
| 空结果/覆盖范围说明 | `coverage` UI 契约、舰桥和工作流提示 | 无结果仅表示本次有界任务或来源未命中，不能表述为材料文献或现象不存在。 |

## 有意差异

1. **凭据管理**：FrontierLens 的网页设置页不移植。CosMatter 的 API 密钥只允许留在受保护的上级 `.env`；浏览器、UI JSON、localStorage 和运行日志均不接触密钥。
2. **全文阅读**：不从远程服务批量分页、缓存或展示整篇论文。MinerU 仅提供经授权后的结构化解析入口，随后由人工选择小型 `source_map`。
3. **生成式导读**：计划草案可以使用受控模型，但运行、证据和结构关系都必须由人工批准工件与来源定位闭合，不能由模型创建科学事实。
4. **跨源同一性**：OpenAlex Work ID 与 Crossref DOI 不会被自动视为同一目标。需要显式、可审计的标识映射后，才可以声称交叉核验。

## 仍待完成的高价值项

1. **浏览器级端到端验证**：已有 `preview-ui`（仅绑定 `127.0.0.1`、只服务 `web/`、禁止浏览器网络连接）、静态资产、导出边界和 JavaScript 语法测试；已实测页面导航、三主题切换和论文导读/结构视图切换。仍需把键盘操作、错误 JSON、空工件和截图基线纳入可重复的自动化测试。
2. **可中断的长期任务**：若引入队列、后台 worker 或批量外部请求，取消令牌必须进入每一个可中断边界，而不只是写本地取消标记。
3. **跨源标识映射审计**：Crossref DOI 与 OpenAlex Work 的对照必须保留映射依据、时间和冲突状态，不能以同名或单源缺失推断等价/不存在。
4. **材料单位本体**：当前仅保留证据卡的原始字段名和单位后缀；若要比较或换算，需引入人工审核的单位/量纲映射，而不是在 UI 中隐式换算。

## 验证口径

每项已对齐能力必须同时满足：有明确工件契约、受控 CLI 或导出路径、前端仅消费白名单字段、以及覆盖该边界的无密钥测试。页面演示、模型草案或单一元数据来源本身都不能作为材料科学结论的证据。
