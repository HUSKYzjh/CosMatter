# 文献图谱工作台

## 目标

将一个已界定的研究任务呈现为三个互相切换、共享同一份脱敏 UI JSON 的阅读入口：

1. **Paper cards**：用于快速比较论文候选的元数据、来源和可访问性；
2. **Network**：按 Papers、Evidence、References、Structure 四类工件聚类，展示可追溯的关系；
3. **Map signals**：显示阅读面、证据门禁、书目扩展、年份覆盖和来源覆盖。

这个信息架构借鉴了 Frontier Lens 的“问题卡片—关系网络—阅读路线”工作流，但不复制其数据假设：CosMatter 的图只来自一个任务的有界工件，而不是开放世界的知识结论。

## 数据与边界

前端只消费 `literature_graph` 投影。节点必须携带 `kind`、`trust_status`，可选的 `source`、`publication_year`、`is_content_accessible`；边必须携带 `edge_type`、`relation_source` 与 `trust_status`。

| 图谱层 | 允许的工件 | UI 含义 |
| --- | --- | --- |
| Papers | 检索候选、已解析论文、关系根论文 | 可能的阅读对象，**不是**材料结论 |
| Evidence | 已接受短证据及其来源论文 | 通过证据审核路线的工件 |
| References | OpenAlex/Crossref 关系节点 | 书目导航或算法推荐来源 |
| Structure | 论文内结构化实体 | 已审核文档中的局部结构 |

候选、元数据关系、算法相关性与已审核证据使用不同颜色、筛选项和文字标签。图谱页明确提示：关系连线仅用于导航和溯源，不表示材料因果性，也不替代证据复核。

## 交互

- 节点类别、关系类别和标题/来源搜索可组合过滤；
- 选择节点后可启用“Focus selection”，仅保留其局部邻域；
- 选择边后，检查器展示关系类型、来源以及信任边界；
- 卡片页可跳回对应的网络节点；
- 洞察页的年份、来源数量与链接数量均由当前可见的投影计算，不调用模型、不发起网络请求。

## 实现位置

- `frontend/src/GraphNetwork.tsx`：三视图、筛选与检查器；
- `frontend/src/graph-lens.css`：与三套主题变量兼容的图谱样式；
- `cosmatter/ui_export.py`：受数量上限保护的 `literature_graph` UI 投影；
- `tests/test_ui_literature_graph_projection.py`：投影和脱敏边界测试。
