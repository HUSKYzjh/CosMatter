# UI audit summary boundary

The Reading and Research Extension workspaces display only aggregate audit
state: report identifier coverage, exact source-map match counts, manual-locator
counts, and the number of Sciverse retrieval receipts. They do not receive audit
items, evidence quotes, source-map text, local paths, query text or digest,
provider request IDs, credentials, or raw provider responses.

Use the local JSON audit artifacts for detailed review. The UI summary is a
navigation aid, not evidence provenance by itself.
