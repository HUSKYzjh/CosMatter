# AiiDA 隔离试点授权与验收清单

此清单是从当前本地 `aiida_mock` 进入真实 AiiDA 适配器前的人工决策工件。它不是配置文件、命令脚本或凭据存储；不得把校园账号、密码、令牌、主机地址、队列名、私有路径、结构文件或赝势放进仓库、`.env`、浏览器 bundle 或运行工件。

## 1. 需要明确填写并批准的范围

| 项目 | 必须明确的值 | 当前状态 |
|---|---|---|
| 研究问题与已审核 EvidenceCard | 一个任务、一个可证伪假设、对应 EvidenceCard ID | 待选择 |
| 公开结构 | 可公开再分发的结构标识、来源许可与内容哈希 | 待选择 |
| 唯一配方 | 仅一个“弛豫 → 静态性质”AiiDA 配方/代码插件版本 | 待选择 |
| 资源上限 | 最多 1 个任务；CPU/GPU/核时上限；停止条件 | 待批准 |
| 执行环境 | 由研究者在 AiiDA/HPC 端维护的受控 profile/别名 | 待研究者确认 |
| 结果保留 | 仅 process UUID、状态、资源摘要、输入/输出哈希与聚合结果 | 固定 |
| 回滚 | 可取消；失败或超预算时停止；不自动重试超过批准次数 | 固定 |

## 2. 允许与禁止

允许的 CosMatter 记录：已审核计划绑定、外部 AiiDA process UUID、脱敏状态、资源摘要、输入/输出 SHA-256、已人工审核的聚合数值。

禁止：把 AiiDA 数据库、远程目录、队列脚本、原始波函数/轨迹、私有结构、校园认证信息或商业软件许可信息复制到 CosMatter。

## 3. 试点前的必须验收

1. 当前 `SimulationCampaign` 已批准，且其证据、协议、输入哈希和人工审核链验证通过。
2. 公开结构和所用输入的许可经过人工确认；结构内容哈希冻结。
3. 执行人确认 AiiDA profile 已在其私有执行环境中可用；CosMatter 不读取 profile 配置或凭据。
4. 一项任务的资源/超时/取消条件被书面批准；无 GPU 或 DFT 批量扩展。
5. 真实适配器在无网络、无凭据的 fake client 回归中覆盖 submit/poll/cancel/retry/resume，且拒绝所有非 allowlist 配方。
6. 隔离试点完成后，只导入 P1 的 aggregate receipt；它仍必须经人工审核，不能自动进入 EvidenceCard 或报告结论。

## 4. 现在不具备的条件

截至 2026-09，本机未安装 AiiDA，且 CosMatter 的机器配置为 `plan_only`、零执行预算。`aiida_mock` 仅用于验证状态机与谱系对象，不能作为真实执行授权的替代。

只有以上项目全部完成并获得单独授权后，才可考虑安装 AiiDA 或在隔离环境中启用受限适配器。
