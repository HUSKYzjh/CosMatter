# CosMatter 评测与证据声明规范

CosMatter 将“系统完成了一步工作”和“科学结论已被证实”明确分开。所有指标、界面状态和提交材料都必须使用本规范中的证据等级与声明范围。

## 1. 四级证据成熟度

| 等级 | 可声明的内容 | 最低条件 | 不可声明的内容 |
| --- | --- | --- |
| 文献提及 | 某一受控来源在特定定位处提到了某现象或结果 | 已授权来源、Source Map 定位、人工确认的短片段 | 该说法正确、普遍成立或可复现 |
| 有数据支撑 | 被审阅的事实或证据卡在已记录条件下支持/反驳一个限定说法 | 可追溯 Source Map、条件字段、审核通过 | 跨条件的因果解释或完整性结论 |
| 可复现 | 给出了能由他人执行和判定成败的验证方案 | 变量、对照、范围、失败判据及可访问的方法边界 | 已在独立环境得到相同结果 |
| 已经复现 | 独立执行记录支持同一受限结论 | 保存的执行记录、结果比对、偏差说明与人工审查 | 超出声明范围的普遍定律 |

证据成熟度登记册只会在来源链接审计与敏感工件审计均通过后投影到 UI 或提交清单；浏览器导入本地 JSON 时不会重新读取私有 Source Map，因此必须把它理解为“导出时已验证”的声明，而非浏览器中的再次验证。

## 2. 评测对象与有效范围

合成冻结样例用于回归测试：它能证明代码、契约和门禁在固定输入下保持工作，不能证明真实文献集上的检索效果、模型质量或材料科学正确性。

真实语料评测必须以人工确认的冻结书目清单和人工金标准为界。候选只能通过唯一且精确的 DOI 映射进入该边界；标题、作者、年份、语义相似度或模型判断都不能替代该映射。不同检索路线比较时，任务、冻结语料、K 值、人工标签群体和身份解析策略必须相同。

## 3. 可报告的指标

在完整人工审核后，系统可报告以下聚合指标：

- 检索：Precision@K、Recall@K、nDCG@K；
- 材料事实：Precision、Recall、F1、单位匹配准确率；
- 证据质量：引文定位准确率、条件完整率、矛盾标签准确率；
- Research Gap：专家批准率、创新性/可执行性/证据完整性汇总，以及已检查的反证边界。

缺少适用的人工审核结果时，状态必须是“等待人工审核”或“未生成”，不能以 0 分、空图或自动文字暗示失败或通过。每个已报告指标应能追溯到同一运行中的聚合评测工件；详细流程、公式和模板见 [真实语料评测](real_corpus_evaluation.md)。

## 4. Research Gap 的保守解释

Research Gap 是带边界的待审阅假设，不是“全球文献不存在相关工作”的断言。候选必须引用当前任务的已接受证据，并记录条件冲突或证据缺口、可证伪假设、验证行动与已执行反证检索的边界。只有人工专家审核能决定是否将其作为研究建议采纳。

## 5. 提交前核对

提交前运行工作流就绪性和最终提交检查。它们验证工件身份、完整性、人工评测门禁和安全审计；不会替研究者判断科学真伪。对于每项公开文字，先确认它属于上述哪一级、条件范围是什么、是否有独立复现记录，以及是否将限制一并写明。
